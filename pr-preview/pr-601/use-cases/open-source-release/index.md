# Ship the tag. Tell every channel, as you.

> Announce a release on Slack, Hacker News, Reddit, LinkedIn, X and Bluesky, and rally reactions on the GitHub issue, from one queue, as you.

## Sound familiar?

- **Schedulers skip developer channels.** None of the schedulers we checked support Hacker News, and most skip GitHub and Slack.
- **Maintainers are scattered.** Everyone means to share the release. Few remember in the first hour.
- **One spammy post costs trust.** Developers notice votes, blast posts and bot-branded messages.

## How Blowhorn runs it

- **Every developer channel, one queue.** GitHub reactions, Slack as you, Hacker News submit and comment, plus LinkedIn, X, Reddit and Bluesky, from one queue.
- **Amplify from your profiles.** Queue the release from every profile you run, each posting as itself. Team invites are coming soon.
- **Slack as you, no bot to invite.** Sends as you through Slack's API, using your Slack session linked through the Blowhorn extension or a Slack token you add. Either one is kept in your Blowhorn account.
- **Human-paced by design.** Types key by key in your own browser for LinkedIn, X, Reddit and Hacker News. Caps itself. CAPTCHA and 2FA stay with you.

## Or tell your agent

"Draft the release posts from CHANGELOG.md, react on the GitHub issue, submit to Hacker News, then --dry-run the rest."

## Frequently Asked Questions

**Does it vote on Hacker News?** Never. It submits stories and comments, nothing else. Link submissions are capped at 2 per profile per day.

**Does Blowhorn install a Slack app?** No. Blowhorn works on Slack through Slack's API, never the browser, and sends as you with your Slack session, linked through the Blowhorn extension, or a Slack token you add. Either one is kept in your Blowhorn account.

**Does every maintainer need macOS?** Each computer that acts needs macOS 13 or newer today. Windows and Linux: not today. The queue lives in your Blowhorn account.
