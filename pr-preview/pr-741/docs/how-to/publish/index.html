Publish

Queue a post, preview it, publish it, reply, and amplify.

Add posts to the queue, preview them with a dry run, publish them to several profiles at once, and amplify what worked: reposts, retweets, quotes, upvotes, and GitHub reactions. Reply and comment from the queue too. For YouTube uploads, Posts-tab posts, comments, replies and likes, see Post to YouTube.

Post content

Preview and publish queued posts across profiles and platforms.

Manage the content queue

Add, edit, and track queued posts under Activity › Upcoming and from the command line.

Amplify an existing post

Repost, retweet, quote, upvote, or react to a post from every profile.

Amplify an issue or pull request on GitHub

React to GitHub issues and pull requests from every profile.

Post to Reddit and Bluesky

Queue Reddit posts and Bluesky posts, threads, and reposts.

Post to Hacker News

Submit links and text posts, comment, and stay within the daily cap.

Post to YouTube

Upload a video, post on the Posts tab, comment, reply, like, and collect analytics, with the behavior of each activity.

Reply to a post

Comment on LinkedIn, Reddit, and Bluesky activities, and reply on X.

Send a Slack message

Queue Slack activities or send one message typed on the command line.
