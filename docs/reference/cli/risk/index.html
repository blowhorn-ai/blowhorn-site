blowhorn risk

blowhorn risk: grid, set, show.

The blowhorn risk commands. Each one's --help prints the same text.

Command What it does
risk grid Show the Risk Profile of every profile on every platform at once.
risk set Choose a Risk Profile: cautious, standard (the built-in default) or brisk.
risk show Show the Risk Profile in effect for each platform.

blowhorn risk grid

Show the Risk Profile of every profile on every platform at once: the choice for everyone, each platform's choice for every profile (and whether it is kept for every computer or on this computer only), each profile's own choice, and for each profile on each platform the preset in effect, the level that chose it, and whether it is still warming up and running cautious. Reads the store once.

Flag Type Default Description
--json boolean false Emit machine-readable JSON output
--platform string Platform scope for blowhorn risk. One of: bluesky, github, hn, linkedin, reddit, slack, x, all (all means every platform listed here)
--pace string Accepted by blowhorn risk grid because --pace is a global flag, but this command does no paced work -- it sleeps between nothing -- so the value changes nothing about how it runs and appears only in the Pace column of the -v summary. Resolved as CLI flag, then BLOWHORN_PACE, then defaults.pace in .blowhorn.yaml (normal when none is set); an unrecognized value is rejected before anything runs
--risk-profile string Accepted by blowhorn risk grid because --risk-profile is a global flag, but this command does no gated work -- no Risk Profile hold, cap or pace applies to it -- so the value changes nothing about how it runs. A value after the command word wins over one before it; an unrecognized value is rejected before anything runs

Also takes the shared flags: --config, --log-dir, --profile, --exclude, --headless, --chrome-launch, --headed, --dry-run, --verbose.

Output: json with --json, text otherwise.

blowhorn risk set

Choose a Risk Profile: cautious, standard (the built-in default) or brisk. With no --profile and no --platform it is written to .blowhorn.yaml (defaults.risk_profile). With --platform alone it is the choice for every profile on that platform, saved for your whole organization so every computer reads it; when it cannot be saved there (your account does not keep it yet, you are not an organization admin, or the store cannot be reached) it is kept on this computer in .blowhorn.yaml (defaults.risk_profile_by_platform) and the command says so. With --profile it is stored on that profile in the store (Risk Profile, or Risk Profile By Platform with --platform). When a platform's choice and a profile's own choice differ, the more careful one applies. default clears the choice at that scope (for a platform, on this computer too). --dry-run says what would change and writes nothing.

blowhorn risk show

Show the Risk Profile in effect for each platform: the one chosen, the level and the source that chose it (--profile reads that profile's choices from the store; every run also reads the organization's choice for each platform, .blowhorn.yaml, BLOWHORN_RISK_PROFILE, your account's choice and the built-in standard) and what the preset sets. When a platform's choice and a profile's own choice differ, the more careful one applies. A new profile or computer still runs cautious until it is warm, whatever is chosen.
