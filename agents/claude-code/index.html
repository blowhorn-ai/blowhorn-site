Blowhorn for Claude Code

Claude Code already lives in your terminal. Give it the Blowhorn CLI and a skill, and it runs your launch while you review the diff.

+

How it works

  1. 1

    Install Blowhorn

    Blowhorn for your computer and the Blowhorn browser extension. Your posts go out from your own signed-in browser.

  2. 2

    Teach it once with a skill

    Skills, CLAUDE.md and a Bash allowlist. A few lines and Claude Code knows the commands.

  3. 3

    Say what you want

    Claude Code turns it into blowhorn commands. You approve what publishes.

Teach it once with a skill

Claude Code loads project skills from .claude/skills/. Add one that lists the blowhorn commands, says reads take --json and writes pass the row fingerprint back. Allow read-only commands in .claude/settings.json and leave publishing on ask.

Try saying

  • You say: "Read my pending content queue and tell me which rows are owed to which profiles before Tuesday."

  • You say: "Add a LinkedIn row for your personal profile: announce the v2.4 release, approved, promote on 2026-11-10 09:00:00. Show me the payload first."

  • You say: "Our post just went live at this URL. Dry-run an amplify from every profile on this computer, then wait for my go."

  • You say: "Something is off with LinkedIn. Pause the whole fleet and tell me the reason you recorded."

Frequently Asked Questions

Does Blowhorn ship an MCP server for Claude Code?

Yes. Add the Blowhorn MCP server to Claude Code and it can find and use every Blowhorn action, with your limits and approval rules attached. Prefer the shell? The CLI speaks --json, so a skill and an allowlist work too.

Can it publish without asking me?

Only if you allow it. Keep blowhorn post and schedule trigger-now off the allowlist and Claude Code asks every time.

Does my agent see my social passwords?

No. Blowhorn posts through your own signed-in browser; the agent only runs commands and reads their output. Review what you allow it to run, as with any tool that acts on your accounts.

What Claude Code can do on each platform

Every action below is a blowhorn command Claude Code can run for you. Each platform's docs page has the details.

PlatformActionHow it behavesLimits
LinkedIn Post Publishes your message to your LinkedIn feed, to a group, or to a Page you manage, with an image or link preview when you add one. None
Comment Comments on the LinkedIn post you point it at. Anything that isn't a LinkedIn post address stays a normal post. None
Amplify Reposts a post from each of your profiles. A post you already reposted is never reposted twice. None
Accept Accepts the invitations people sent you, one at a time. An invitation LinkedIn flags with its "Take care when connecting" warning is skipped, never accepted. At most 20 confirmed acceptances a run, unless you set --limit.
Withdraw Withdraws invitations you sent that have waited 21 days or more, to free room for new ones. Shows a preview until you add --apply. At most 20 confirmed withdrawals a run, unless you set --limit. LinkedIn blocks re-inviting a withdrawn person for up to three weeks.
Analytics Reads your Page's analytics for a date range and saves them, so you can watch the trend. Read-only.
X (Twitter) Post Publishes your message, with an image if you add one. A message longer than 274 characters goes out as a thread. X publishes 50 original posts a day for an account without a checkmark, and no setting in Blowhorn goes past it.
Reply Replies in a conversation when your post is addressed to it. X publishes 200 replies a day for an account without a checkmark, and no setting in Blowhorn goes past it.
Amplify Retweets or quotes a post from each of your profiles. None
Follow Name a target account. With --limit 0, follow that account, or several comma-separated. With a positive limit, follow up to that many of the target's followers, never the target itself, skipping anyone you already follow. At most 400 follows per profile a day, and 15 in any 15 minutes, counted from that profile's follow log on this computer.
Analytics Records your follower and following counts on each run, so you can watch the trend. Read-only.
Reddit Post Publishes your post to the subreddit you name, as r/<name>. A post with no subreddit is skipped, never guessed.
Comment Comments on the Reddit post or comment you point it at. None
Amplify Upvotes a post from each of your profiles. None
Hacker News Post Submits a link or a text post. Titles hold up to 80 characters; a longer title is refused, never cut short, because a submission can't be edited once it's up. At most 2 link submissions per profile per UTC day; only link submissions are recorded, so only they count toward the cap. Preview first with --dry-run, because every submission is permanent. Blowhorn never votes.
Comment Comments on the Hacker News item your post is addressed to, under your name. None
Slack Post Sends a message as you to a channel or to a person, as #channel, @user, a channel ID, or a channel link. Shows a preview until you confirm. One profile sends per run. A target Blowhorn can't read is refused, never sent somewhere else.
Reply Replies in a thread when you give it the link to the message. None
Bluesky Post Publishes your message. A message longer than 300 characters goes out as a thread. None
Reply Replies to the Bluesky post you point it at. None
Amplify Reposts a post from each of your profiles. None
Follow Name a target account. With --limit 0, follow that account, or several comma-separated. With a positive limit, follow up to that many of the target's followers, never the target itself. None
Unfollow Unfollows one account. None
Find Searches Bluesky posts for the words you give it. None
Analytics Records your follower and following counts on each run, so you can watch the trend. Read-only.
GitHub React Adds the five upbeat reactions (+1, laugh, hooray, heart, rocket) to an issue or pull request from each of your profiles. Running it again adds none of them twice. GitHub doesn't publish posts; it needs an issue or pull request link.
Follow Name a target account. With --limit 0, follow that account, or several comma-separated. With a positive limit, follow up to that many of the target's followers, never the target itself. None
Find Lists the people around a repository, so you can choose whom to reach. Lists only; it doesn't follow or react.
