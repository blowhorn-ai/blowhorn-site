# Agentic AI Marketing

> Your coding agent can ship the release. Now it can announce it too.

Run your marketing from the AI agent you already code with. Blowhorn's CLI does everything the desktop app does, so Claude Code, OpenCode, Pi, Codex, Grok and DeepSeek can schedule and amplify for you.

- [Claude Code](https://blowhorn.ai/agents/claude-code/): Skills, CLAUDE.md and a Bash allowlist
- [OpenCode](https://blowhorn.ai/agents/opencode/): AGENTS.md and per-command permissions
- [Pi](https://blowhorn.ai/agents/pi/): A minimal agent with a bash tool
- [Codex](https://blowhorn.ai/agents/codex/): AGENTS.md, codex exec and approvals
- [Grok](https://blowhorn.ai/agents/grok/): Prompts in, blowhorn commands out
- [DeepSeek](https://blowhorn.ai/agents/deepseek/): Any harness, one CLI
- [CLI](https://blowhorn.ai/agents/cli/): Every app feature, as a command

- **Everything is a command**: The CLI does everything the desktop app does, so any agent with a shell can drive Blowhorn.
- **A fleet behind every post**: Every computer signed in to your account works one schedule, coordinated so the same post isn't sent from two computers.
- **Your hand on the switch**: schedule pause --all stops every computer at once. --row N parks one job everywhere.
